# Retired Prompt 15 grid tooling

Prompt 19-01 removed the global synthetic grid from the active application.
Former grid generators, repair/verification commands and their orchestration
entrypoints are retained here as `.txt` source records. They are historical
evidence, are excluded from executable tests, and cannot run via their former
Node/npm commands. Shared coarse source data and source locks remain in place.

The current offline packaging command is `npm run data:world`.
