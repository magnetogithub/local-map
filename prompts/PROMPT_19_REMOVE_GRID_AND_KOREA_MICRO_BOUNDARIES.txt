## 1. 목표와 용어

- 제거 대상은 현재 92만 셀 운영 catalog와 그 격자 생성·로딩·전달 체계다. 화면에서 경계선을 숨기거나 한국·북한 overlay만 덧붙이고 92만 셀 world를 유지하는 것으로 완료하지 않는다.

- 새 셀 개수는 원본 경계의 수준과 실제 플레이 정밀도에 따라 정한다. 923,443개 유지나 특정 개수 맞추기를 요구하지 않는다.

2. 국가 윤곽과 기존 coarse 영토를 사용하는 기본 world를 연결해 구 92만 셀 초기화·migration·ID 배열 전달·전체 incidence 로딩을 제거한다. 단계 종료 시 기본 지도와 새 게임이 부팅돼야 한다.
3. 구 격자 전용 생성 코드·활성 CLI·fallback·배포 tracing과 전용 테스트 전제를 정리한다. 공유 가능한 catalog/점령/전선 코드는 재사용한다. 명령 실행이나 오류 복구로 구 격자를 자동 재생성하지 않아야 한다.
4. 의존성이 제거된 구 92만 셀 전용 catalog·topology/membership·타일·상세 geometry·metadata·runtime 복사 산출물은 실제 삭제한다. 단순 비활성화나 주석 처리만으로 완료하지 않는다.
5. 재귀 삭제 전 대상의 resolved 절대경로가 확인한 전용 경로 안인지 검증한다. data/derived 전체, data/raw 전체, reports 전체, 공용 입력 디렉터리를 통째로 삭제하지 않는다. 원본과 필요한 한국·북한 경계 자료를 보존한다.
6. 역사 문서·source-lock·기존 승인 기록은 과거 증거로 남길 수 있다. 운영·빌드·테스트 실행이 삭제된 구 산출물을 요구하면 해당 활성 연결을 수정한다. Git history 재작성·GC·저장소 전체 용량 청소는 수행하지 않는다.
7. 구 catalog 세션·캐시를 새 셀에 재해석하지 않는다. catalog 버전별 캐시를 분리·무효화하고 구 세션은 명확히 거부하거나 새 게임으로 전환한다.

완료 조건:

- 새 게임·지도·빌드에 구 923,443개 셀 catalog와 3,125,743개 edge 자료가 필요하지 않다.
- 구 92만 셀 전체 생성·전달·초기 상태 기록이 실행되지 않으며 전용 산출물 삭제 결과가 기록돼 있다.
- 다른 국가의 윤곽·검색·선택과 기본 게임 화면이 유지된다. 이들을 미세화하지 않는다.

### 19-02. 한국·북한 미세 영토 경계 추가

C가 공통 계약을 확정한 뒤 19-02A(A: 한국)와 19-02B(B: 북한)를 병렬 진행한다. 아래 1~3의 원본·국가 내부 geometry 작업과 국가 내부 topology 후보는 각각 담당하고, 공유 국경·최종 topology·catalog 및 앱 연결은 C가 합류 후 수행한다.

1. 3절에 따라 두 국가의 실제 세부 원본을 확인·확보하고 사용할 경계 수준과 선택 이유를 기록한다. 기존 도 전체 선택 문제가 재발하지 않는 정밀도가 필요하다.
2. 두 국가에만 자연스러운 미세 영토 polygon을 만든다. 원본 국가 외곽 안에서 경계를 정합하고 해안·섬·분리 component·polygon hole을 보존한다. 직선 변이 있다는 이유만으로 실제 원본 경계를 임의로 굽히지도 않는다.
3. 한국·북한 각각 기존 ADM1 내부에서 일부만 점령할 수 있는 복수의 영토 단위를 제공한다. 총 셀 수·정점 수·파일 크기는 실제 결과를 기록하고 불필요한 과분할을 줄인다.
4. 국가 내부와 양국 접경의 topology·양방향 adjacency·행정 membership을 새 geometry에서 만든다. 양의 길이 공유 육상 경계만 육상 인접으로 처리한다. 바다·점 접촉을 육상 접경으로 만들지 않는다.
5. 기존 coarse 국가들과 새 KOR/PRK 미세 영토를 하나의 새 catalogRef/ID/ordinal 체계로 연결한다. 새 seed의 source/owner/controller, region lookup, frontier selection, 지도 vector/exact detail이 같은 catalog를 사용해야 한다.
6. 미세 영토와 topology는 오프라인 준비한다. 턴 도중 polygon을 새로 분할하거나 AI가 좌표·polygon·미등록 ID를 생성하게 하지 않는다.
7. 저배율은 연속된 국토 면을 유지한다. 작은 미세 polygon을 개별 제거해 육지에 바다색 구멍을 만드는 방식은 사용하지 않는다. 필요한 배율·영역의 상세와 authoritative 변경 영역·전선을 연결한다.
8. 직사각형 배열·국가별 연속 ordinal 범위를 가정하지 않는다. 새 world 전체를 불필요하게 복사·전송·재파싱하는 구 경로를 그대로 이어받지 않도록 필요한 연결을 고친다.

완료 조건:

- 실제 실행 화면이 새 catalog와 KOR/PRK 미세 geometry를 사용한다. overlay 뒤에 구 92만 셀 world가 남아 있지 않다.
- 두 국가의 세부 경계에 출처가 있고, ADM1 내부 부분 선택과 연속 진격이 가능한 인접 구조가 있다.
- 두 국가 union의 빈틈·중복·외곽 이탈과 섬/component 누락을 확인한다. 저배율 면적 coverage를 확인하며 모든 zoom의 ID 합집합 검사로 대신하지 않는다.
- 다른 나라에는 새 미세 geometry를 생성하지 않는다.

### 19-03. 한국·북한 테스트 및 종료

C가 실제 실행과 실패 수정을 소유한다. A/B는 각 국가 geometry 및 인접·부분 점령 회귀의 읽기 검토를 병렬로 하고 결과를 인계한다. 같은 브라우저·서버·공통 파일을 동시에 조작하지 않는다.

새 catalog에서 새 게임을 만든다. 작은 fixture 검증과 두 국가의 실제 geometry·기존 scripted provider·실제 브라우저 확인을 연결한다. 가짜 map 테스트만으로 최종 완료하지 않는다.

기능 확인:

- 한국·북한 검색·선택·이동·확대/축소·hover/hit identity가 실제 geometry 및 authoritative world와 일치한다.
- 두 국가의 전체 국토와 섬이 저배율·상세 배율에서 빠지거나 찢어지지 않는다. 상세 선택/해제와 늦은 요청에서도 최신 상태를 유지한다.
- KOR→PRK 접경 일부 점령: owner는 PRK로 유지하고 선택된 영토의 controller만 KOR로 변경한다. 같은 북한 도 안의 미점령 영역은 PRK 통제로 남는다.
- PRK→KOR도 독립된 새 테스트 상태에서 확인한다. 특정 actor/target나 구 cell ID·구 개수를 하드코딩한 성공으로 대신하지 않는다.
- 후속 진격은 현재 전선에 이어진다. 비접경·바다 건너·범위 초과·미등록 ID 요청은 기존 계약에 따라 거부하고 부분 commit을 남기지 않는다.
- 새 내부 전선의 완전한 geometry와 점령색을 확인한다. 국가 상세를 닫아도 authoritative 전선이 사라지지 않아야 한다.
- 해방/반환·owner 변경이 있는 양도와 undo/redo에서 대상 셀·색·전선·날짜·revision이 정확히 복원된다.
- 다른 국가의 coarse 상태가 두 국가 행동으로 잘못 변경되지 않는다. 다른 나라 전체 플레이 검증으로 확대하지 않는다.

성능 확인:

- 가능한 기존 기록을 재사용하고 실제 viewport·DPR·카메라·실행 모드·공급자를 기록한다. 초기 지도 준비와 턴 진행 후 지도 반영을 분리한다.
- 새 전체 territory/edge 수, 두 국가의 미세 territory 수, 전달·해제 bytes, 최초 상태 기록과 큰 전체 순회 여부를 기록한다.
- 큰 메인 스레드 정지·클릭/이동 반응·가능한 CPU/working set을 짧게 확인한다. 작업량 감소와 실제 시간 감소를 구분한다.
- 과거 92만 셀 기준 기록과 조건이 다르면 개선율을 계산하지 않는다. 이미 삭제한 구 체계를 성능 비교만을 위해 재생성하지 않는다.
- 느린 지점이 남으면 현재 두 국가 시나리오의 직접 원인만 수정·재확인한다. 전 세계 성능 전면 개편으로 확대하지 않는다.

관련 테스트·타입 검사·lint·사용 가능한 production build를 실행하고 실패를 해결한다. 같은 변경에 이미 유효한 검증은 재사용하며 불필요한 반복 검사·전체 카탈로그 재감사를 피한다.

최종 기록과 종료:

- reports/maintenance/ 아래 Prompt 19 결과를 하나의 짧은 보고서로 남긴다.
- 구 체계의 실제 삭제 경로·남겨둔 역사 증거, 새 catalog/version·원본 출처/허가, 두 국가 셀/edge 수와 크기를 기록한다.
- KOR→PRK, PRK→KOR, 연속 진격·해방/양도·undo/redo의 결과와 실제 화면 증거, 성능 조건·관측·한계를 기록한다.
- 미확보 자료나 미검증 기능이 있으면 완료 여부를 분명히 구분한다. 도형만 자연스럽게 보이거나 셀 수만 줄었다는 이유로 전체 통과를 선언하지 않는다.
- 여기서 종료한다. 다른 국가의 미세 경계 생성·전 세계 rollout·추가 프롬프트 실행은 별도 사용자 요청으로 남긴다.
